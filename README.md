# RV Testing Machines Private Limited — Official Website

NABL Accredited (ISO/IEC 17025) Material Testing Laboratory & Calibration Services.

## Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Vanilla CSS Design System
- **Routing**: React Router v7
- **Deployment**: Cloudflare Workers / Pages SPA

## Development & Build Commands
- `npm run dev` — Launch local development server
- `npm run build` — Production build with automatic SEO injection
- `npm run lint` — Run ESLint code quality checks
